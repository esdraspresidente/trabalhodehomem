# Trabalho de Homem — site

Landing page de https://trabalhodehomem.com.br (GitHub Pages, publica sozinho a cada commit na `main`).

- `index.html` — página única. Listas editáveis no fim do arquivo: `DEPOIMENTOS`, `FOTOS`, `CIDADES`.
- `fotos/` — imagens 800×1000 sem EXIF (~150 KB) e vídeos de ~12 s, 720×900, H.264 sem áudio (≤ ~1,3 MB).
- `CNAME` — domínio próprio. Não apagar: sem ele o Pages volta para o endereço github.io.
- Conversão do Google Ads: preencher `ADS_ID`, `WA_LABEL` e `TEL_LABEL` no topo do `index.html`.
